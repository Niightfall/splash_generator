# Splash Generator

This context defines image artifacts prepared for Android and Flutter application launch experiences.

## Language

**Android splash image**:
A generated raster artifact intended for use inside an Android launch experience. It is distinct from the platform's complete splash-screen resource contract.
_Avoid_: splash screen, launch image

**Android splash screen**:
The platform-managed launch experience shown while an Android activity starts, including its background, icon, theme handoff, and resource rules.
_Avoid_: Android splash image
